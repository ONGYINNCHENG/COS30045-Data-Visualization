About This Project

This website is built for COS30045 – Data Visualisation at Swinburne University of Technology.

Project Purpose

The objective of Exercise 0.2 is to establish clean multi-page web development practices using HTML5, external CSS styling, and client-side JavaScript. It reinforces regular Git version control and proper documentation of Generative AI assistance.

Technical Specifications

  • Frontend Stack: HTML5, CSS3, Vanilla JavaScript.
  • Hosting Target: Swinburne Mercury Apache Web Server.
  • Version Control: Git & GitHub repository.
